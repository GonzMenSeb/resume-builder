### Page Compaction
- Automatic compaction when PDF exceeds `max_pages`
- Removes lowest-priority bullets while respecting `min_bullets_per_job`
- Up to 5 compaction rounds

### New CLI Commands
- `resume-gen init`: Create configuration file
- `resume-gen config`: Show current configuration

### New CLI Options
- `--config PATH`: Use specific YAML config file
- `--colors, -c PALETTE`: Set color palette
- `--max-pages, -p NUMBER`: Set maximum pages (1-3)
- `--max-bullet-words, -w NUMBER`: Set max words per bullet (10-50)
